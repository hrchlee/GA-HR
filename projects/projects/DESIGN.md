# 프로젝트 보드 설계

사용자 확정 요구: GA-HR 저장소에 독립 HTML 프로젝트 보드를 추가한다. 인사관리와 Firebase에 연결하지 않는다. 일별 가로 날짜/세로 업무, 담당자 미지정, 준비 체크리스트, 날짜별 기록과 공동 편집을 지원한다.

GitHub 저장소가 HTML과 프로젝트 JSON의 원본이다. 공개 조회는 인증 없이 GitHub API를 사용하고, 편집은 저장소 협업자의 Contents 쓰기 권한을 가진 토큰을 현재 탭 메모리에서만 사용한다. 개별 프로젝트의 앱 자체 접근 권한 체계는 두지 않고 GitHub 권한을 따른다. 저장소 SHA와 업무별 version을 함께 비교해 변경을 보존한다. 충돌 시 입력을 유지한다. 편집 중 30초, 조회 중 2분 갱신 및 수동 새로고침을 제공한다.

네이비 프로젝트 목록, 밝은 작업 화면, 오늘 전후 35일 격자와 상태별 막대, 오른쪽 업무 상세 패널. 샘플은 공용 데이터와 분리하고 새로고침하면 초기화한다. 기존 저장소의 index.html은 변경하지 않는다.
