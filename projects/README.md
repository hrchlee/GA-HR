# 모아 · 프로젝트 보드 (구글 시트 저장 버전)

화면은 GitHub Pages(`/GA-HR/projects/`)에서 열리고, 데이터는 구글 시트에 저장됩니다.
팀원은 링크만 열면 가입·로그인 없이 바로 보고 편집할 수 있습니다. 처음 편집할 때 이름을 한 번 입력하면 기록에 그 이름이 남습니다.

## 1. 구글 시트 준비 (관리자 1회)
1. 구글 드라이브에서 새 스프레드시트를 만듭니다. (예: 모아 프로젝트 보드 데이터)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 승인 → 표시되는 **웹 앱 URL**(…/exec로 끝남)을 복사합니다.

## 2. GitHub에 반영
1. `sheets-config.mjs`의 `여기에_웹앱_URL_붙여넣기`를 복사한 URL로 바꿉니다.
2. 저장소 `projects/` 폴더에 이 폴더의 파일을 올립니다(덮어쓰기).
3. 더 이상 쓰지 않는 파일은 삭제합니다: `github-config.mjs`, `github-store.mjs`, `data/board.json`, `tests/github-store_test.mjs`, `tests/model_test.mjs`

## 알아둘 점
- 시트의 `data` 시트는 앱 전용 원본이므로 직접 수정하지 마세요. `업무현황` 시트는 저장할 때마다 자동 갱신되는 보기용 목록입니다.
- 되돌리기가 필요하면 시트의 **파일 → 버전 기록**을 이용합니다.
- 30초마다 자동 갱신되며, 같은 업무를 동시에 고치면 나중 저장이 거부되고 입력은 유지됩니다.
- 링크(와 웹 앱 주소)를 아는 사람은 누구나 보고 편집할 수 있으니 팀 내부에서만 공유하세요.
- Apps Script 코드를 수정했다면 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.
